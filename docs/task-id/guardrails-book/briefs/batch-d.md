## 10-전자정부프레임워크의-가드레일.md

구성 제안:
- 도입: 한국 행정 정보화의 축 — 표준프레임워크(전자정부프레임워크)와 공통컴포넌트. '공통 검증 계층·개발표준 강제'는 프레임워크 수준 가드레일의 전형(필자 각색 관점)
- 절1 — 상호운용성 논문 정독(2608.14568): AI 거버넌스에 ISO류 상호운용 프로토콜이 필요하다는 논지를 소개하고, 한국 행정의 표준·인터페이스 체계(행정 정보시스템 간 연계)와 겹며는 지점 서술
- 절2 — 공공 디지털 전환 논문(2305.05551): 공공 부문 디지털 전환의 대상·구조 논의 도입, 한국 전자정부의 위상(세계 최초 수준의 전자정부법·온라인 민원 인프라 — 일반 서술로, 과장 없이)
- 절3 — 각색: 민원 처리·행정 시스템에 AI 에이전트가 들어온다는 상상. '정책 환경'의 행정 버전 = 법령·행정규칙·업무 지침의 형식화. 결재 흐름(기안→합의→결재)은 원본 논문의 승인 루프와 동형(필자 각색 명시). 공무원 에이전트가 민원 처리·통보를 자동화할 때 증명 게이트가 무엇을 보장하는가
- 절4 — 한계와 현실: 전자정부프레임워크의 실행 의미(공통컴포넌트·검증), 형식 검증 도입까지의 거리(데이터 표준→API 계약→속성 검증의 단계적 사다리)
- 표 1개 가능: 행정 시스템 개념 ↔ Lean-Agent 개념 대응(정책 환경↔법령집, 승인 루프↔결재, 오류 트레이스↔감사 증적)

## 11-CMS-PMS-Slack의-가드레일.md

구성 제안:
- 도입: 콘텐츠·프로젝트·협업 도구는 '누구나 쓰는' 기업 IT — 여기서 가드레일은 특히 콘텐츠 무결성·승인·권한의 문제
- 절1 — 헤드리스 CMS 논문(2508.19797): 콘텐츠를 정보시스템의 일등 시민으로 다루는 모델 기반 통합 — 콘텐츠 모델·스키마가 곧 타입 계약. CMS 발행 전 검증 게이트(필수 필드·참조 무결성·콘텐츠 모델 위반 차단)는 사전거래 통제의 콘텐츠 버전
- 절2 — 디지털 동료 논문(2606.14502): 챗봇을 넘어 디지털 동료로 가는 LLM 인지 코어의 진화 — Slack류 협업 공간에서 에이전트가 상주하는 근미래. 챗옵스(대화로 배포·운영 명령)가 주는 속도와 위험
- 절3 — 각색: PMS(프로젝트 관리)·기안 결재 흐름 = approval 루프의 기업 일상 버전. Slack 봇의 명령 승인·채널 권한 스코프·인간 개입 지점(in-the-loop) 설계 = 오케스트레이터의 축소판(필자 각색 명시)
- 절4 — 웹디자인: 디자인 토큰(색·간격·타이포 값의 불변 집합, DTCG 표준화 흐름)·접근성 대비 검증(자동 체크 가능한 결정론적 규칙) — '디자인 시스템 = 시각 언어의 정책 환경'이라는 유비
- **다이어그램 1개 권장(선택 아님, 되도록 포함)**: layout `flow` — 콘텐츠 발행 승인 게이트(초안→스키마 검증→승인→발행, 검증 실패 분기). 규약: `skills/korean-ebook/references/diagram-authoring.md`
