## 03-Lean-4의-문법.md — 증명을 검사하는 커널 (원문 §2.1 + 배경 각색)

이 장은 원문이 압축 서술한 배경을 한국 독자용 강의로 확장하는 각색 장(필자 각색임을 서두에 명시).

필수 포함:
- 형식 검증이란: 속성을 모든 가능한 상태 공간에서 만족함을 기계적으로 보장(안전 필수 하드웨어·항공우주에서 유래)
- Lean 4: 의존 타입(dependently typed) 형식 언어, Calculus of Inductive Constructions(CIC) 규칙 체계, Mathlib 종합 수학 라이브러리
- 증명 생성 ≠ 증명 검사 분리(2.4장 복선 1문단): 생성은 느려도 되고 검사는 빠르다 — 커널은 최소한의 C++ 프리미티브로 신뢰 기반 좁히기
- `sorry` 전술: 미증명 구멍 표기 — 에피스테믹 갭. Aristotle이 이 구멍을 스스로 메운다(4장 예고)
- Lean4Lean(arXiv 2403.14064): Lean 타입검사기 자체를 Lean으로 검증 — 검증자를 검증
- AWS Cedar '검증 주도 개발(verification-guided development)' 한 문단(9장에서 확장)
- Lean 코드 예시 1개 이내: 개념 이해를 돕는 유사 코드펜스(예: 한도 초과 주문 정리의 의사 표현). 실제 문법 정확성이 불확실하면 '의사 코드'라고 명시
- 절 구성 제안: `### 수학으로 짓는 울타리` / `### 커널이라는 심판` / `### 증명의 구멍, sorry`
