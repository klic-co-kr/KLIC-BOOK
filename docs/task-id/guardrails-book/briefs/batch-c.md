## 06-규제-매핑-한국-금융으로.md (원문 §3.1–3.2 + 한국 각색)

필수 포함:
- 배경 사건: 1987 시장 폭락, Knight Capital 2012(45분·4억 4천만 달러) → SEC Rule 15c3-5 '시장 접속 규칙(Market Access Rule)'
- 15c3-5 요건: 위험 관리 통제·감독 절차의 수립·문서화·유지, (1) 사전 설정 한도(신용·자본) 초과 주문 차단 (2) 오주문 방지(가격·수량 파라미터 초과 거부). 핵심: 통제는 브로커딜러의 '직접적·전속적 통제'하에
- 왜 확률 필터가 규제 실패인가: LLM은 본질적 비결정론(확률적 샘플링·연속 벡터). 99.9% 차단도 '전속 통제' 기준 미달
- Lean-Agent의 응답: 한도·가격 파라미터를 불변 Lean 4 공리로 형식화 → '단단한(hard)' 가드레일. 커널은 의도 해석·확률 추정 없이 이진 진리만 계산. 오류 주문이 시장에 물리적으로 도달 불가능함을 수학적으로 증명
- OCC Bulletin 2011-12(SR 11-7): 모델 리스크 관리(MRM) 프레임워크 — 개발·구현·지속 검증·거버넌스. 전통 MRM은 결정론적 모델 가정 → 생성 AI가 그 가정을 파괴(불투명성·확률 추론·정적 검증 우회 자율 루프)
- FINRA Rule 3110(감독 체계), Regulatory Notice 24-09·2026 감독 보고서: 규칙은 기술 중립 — 생성 AI 도구도 인간 커뮤니케이션과 동일한 엄격함으로 감독
- 원문 핵심 원리: "확률적 '생각'과 결정론적 '행동'의 분리" — 검증 통과 없이는 어떤 에이전트 과제도 실행 불가 → 인간 통제 100% 예측성 시연
- **한국 각색 절(마지막 절, 필자 각색 명시)**: 한국 금융감독의 맥락(전자금융감독규정·정보시스템 감독에서 요구하는 사고 통제·내부통제 구조)을 '한국판 시장접속 통제' 관점에서 논의. 구체 조문 번호·문구는 확정 근거가 없으니 조문 인용 없이 제도 방향 서술로만. 금융 AI 챗봇·로보어드바이저 감독 심화 흐름 언급

## 07-설명할-권리와-역방향-형식화.md (원문 §3.3)

필수 포함:
- '설명할 권리(Right to Explanation)': ECOA·FCRA상 불리 조치(adverse action) 시 구체적·정확·이해 가능한 사유 제공 의무. CFPB: 복잡한 블랙박스 알고리즘·AI 사용이 면책 사유 아님. EU: GDPR·EU AI Act의 자동화 의사결정 설명권
- 문제: Lean 반증 출력은 의존 타입 수학 오류 트레이스 — 차단은 완벽하지만 소비자·비기술 감사인에게 컴파일러 오류를 보여주는 건 법적으로 불충분(쉬운 언어 공개 위반)
- 해법: **역방향 자동 형식화(역번역, back-translation)** — 수학적 실패 상태를 규정 준수 자연어 불리조치 통지로 변환
- 기술 기반: Herald 데이터셋(arXiv 2410.10878) — 정적 분석으로 정리 선언·의존 관계·정확한 증명 상태 추출. 증명 실패 시 정확히 어떤 코드 줄·전술이 거부를 유발했는지 격리(예: Debt_to_Income < 0.43 공리 실패)
- NL2Lean(EMNLP 2025) 접근: 파인튜닝 번역 모델이 격리된 증명 상태를 흡수, RAG 파이프라인으로 단계별 비형식 설명 생성
- 핵심 문장 반드시 포함: 소비자·감사인에게 제공되는 설명은 환각된 논거가 아니라 거부를 강제한 수학적 제약의 1:1 직역

## 08-공격-표면과-WASM-샌드박스.md (원문 §4) — 다이어그램 장

필수 포함:
- '치명적 삼각(lethal trifecta)': 도구 접근 + 자연어 인터페이스 + 신뢰 불가 외부 데이터
- 기존 방어(RLHF·헌법 AI·자동 레드팀)의 반응적·확률적 한계. 형식 기법: 모든 가능한 상태 공간에서 속성 보장 — LLM은 이미 침해됐다고 가정하고 실행 경계를 확보(가정: LLM 침해)
- **번역 계층 취약점**(Lean 커널은 절대적이지만 Aristotle 번역이 공격 표면):
  - 논리적 탈옥(LogiBreak·QueryAttack, arXiv 2505.13527 / ACL 2025 QueryAttack): 악의를 복잡 논리식·비자연 질의어·암호로 번역 — 정렬 학습 분포 밖으로 프롬프트 분포 이동, 의미는 유지
  - 형식화 드리프트·문장 수준 섭동(SLP, arXiv 2506.04575): 재구술·무관 맥락 추가·동의어 치환 → 심볼 드리프트. 간접 프롬프트 인젝션이 제한 변수를 허용 심볼에 매핑시키면 커널이 (그 자체로는 정확하게) 증명 성공 → 정책 위반 승인
  - 완화: MenTaL 개념-심볼 매핑 테이블(번역 전 명시적 구축 강제 — 언어 표현을 하드코딩된 Lean 심볼 레지스트리에 알고리즘 연결), 오케스트레이터의 컨텍스트 수화 정화(정적 파싱으로 필요 변수만 추출·신뢰 불가 외부 텍스트 완전 제거)
- **WASM 샌드박스**: 에이전트 생성 코드 = 적대적 페이로드 전제(원격 코드 실행·파일시스템 조작·유출 위험). Docker 결함: 호스트 OS 커널 공유 → 커널 익스플로잇 시 탈출·권한 상승. WASM 3대 보장: (1) 선형 메모리 모델(지정 블록 밖 주소 가시성 0) (2) 보호 콜스택(힙과 논리 분리 — 제어 흐름 하이재킹 수학적 불가) (3) WASI 역량 기반 보안(파일시스템·네트워크·환경변수 기본 접근 0 — 최소 권한). Lean 검증 환경+에이전트 도구를 모두 WASM으로 컴파일 → 제로 트러스트 실행 경계: 탈옥에 성공해도 실행이 샌드박스 안에 갇힘
- **다이어그램 1개 필수**: layout `layers` — WASM 샌드박스 계층(모듈·선형 메모리·보호 스택·WASI 경계). 규약: `skills/korean-ebook/references/diagram-authoring.md`
