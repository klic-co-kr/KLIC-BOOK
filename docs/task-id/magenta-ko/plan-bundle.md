## 0. 소스 상태 고지 (집필 계약의 전제)

원문 소스(HTML 변환본)에 **보존**된 것: 초록 전문, §2 기호 체계(R·F·P·V_s·V_p·J_s·J_e 전 정의), §2.2 절차 루프, §2.3 예산 부등식, §3·§4 수치 단편(66%/42%·6/120·68%·5/2/5.7·42/17%·58/83%·6×10⁴/9×10⁵ 등), 절제 지표(Table 3·거짓 증명 5건·29/30·1/6), 부록 A 기호표·알고리즘 골격, 부록 B 예산, 부록 C·E 수치표, 부록 F 그림 6, IMO 6문제 풀이 뼈대.

- (G-1) **무앵커 수치 금지** — 소스에 남았으나 문맥을 확인할 수 없는 토큰 `99.2%`, `70.0%`, `8.6`, `25.8`, `2.18.4`는 원고에 쓰지 않는다(claim 9로 검증).
