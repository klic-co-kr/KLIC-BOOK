## 제7장 — 메모리 공식

### KV 캐시는 얼마나 큰가

KV 헤드 수와 헤드 차원이 일치하는 평범한 밀집 어텐션 스택에서, 시퀀스 한 개의 이상화된 캐시 크기는 다음과 같다.

$$M_{KV} = 2\,L\,T\,H_{KV}\,D_h\,b$$

각 기호의 뜻은 다음과 같다.

- 2: K와 V를 동시에 계산에 넣는다.
- L: 어텐션 층 수.
- T: 이미 캐시된 토큰 수.
- `H_KV`: 키/값 헤드 수.
- `D_h`: 헤드 차원.
- b: 저장된 원소 하나가 차지하는 바이트 수.

B개의 등길이 시퀀스에 대해서는 결과에 B를 곱한다. 더 일반적으로, 각 시퀀스의 캐시 길이가 `T_i`일 때 이상화된 유효 데이터량은 다음과 같다.

$$M_{KV} = 2\,L\,H_{KV}\,D_h\,b \sum_{i=1}^{B} T_i$$

실제 추론 서빙 엔진은 메모리를 블록 단위로 할당하며, 패딩·스케일 팩터·메타데이터·샤딩(sharding)·모델 고유의 상태를 더할 수도 있다. 따라서 이 공식들이 서술하는 것은 텐서의 유효 데이터량이며, 런타임에 소비되는 모든 바이트를 담지는 않는다.

이 공식의 가치는 여러 아키텍처 선택의 영향을 한눈에 드러낸다는 데 있다. 문맥 길이는 T를 바꾸고, 멀티 쿼리 어텐션(MQA)과 그룹 쿼리 어텐션(GQA)은 `H_KV`를 바꾸고, 캐시 양자화는 저장 항목인 b를 바꾸는 동시에 양자화 메타데이터를 더한다.
