# GitHub 협업 실무 가이드

AI 코딩 도구를 써도 협업의 기준점은 GitHub다. Claude Code·Codex·Cursor 같은 AI 코딩 도구를 쓸 때, 팀 협업의 중심을 GitHub에 두고 issue·branch·PR 흐름으로 정리한 실무 가이드. GitHub의 말을 일상어로 바꾸고, AI에게 그대로 붙여넣을 수 있는 프롬프트를 중심으로 구성했다.
