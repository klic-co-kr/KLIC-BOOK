# 챕터 표지 정규식 (split_chapters.py Step 4 입력)

한국어·영어 책의 챕터 경계를 감지하는 정규식 패턴. `split_chapters.py`가 본문 헤딩/목차에서 이 패턴으로 후보 경계를 찾는다.

## 한국어 챕터 표지

| 패턴 | 정규식 | 예 |
|------|--------|-----|
| `제N장` | `^제\s*\d+\s*장` | 제1장, 제 2 장 |
| `N장` | `^\d+\s*장(?!\w)` | 1장, 2장 |
| `제N절` | `^제\s*\d+\s*절` | 제1절 (하위) |
| `N장 제목` | `^\d+\s*장\s+\S` | 1장 FDE의 부상 |
| `제N부` | `^제\s*\d+\s*부` | 제1부 (대분류) |

복합(우선순위 순):
```regex
^(제\s*\d+\s*부|제\s*\d+\s*장|\d+\s*장(?!\w))\b
```

## 영어 챕터 표지

| 패턴 | 정규식 | 예 |
|------|--------|-----|
| `Chapter N` | `^Chapter\s+\d+` | Chapter 1 |
| `Ch. N` | `^Ch\.?\s*\d+` | Ch. 2 |
| `N. Title` | `^\d+\.\s+\S` | 1. Introduction |
| `Part N` | `^Part\s+\d+` | Part 1 |

## 부록·후기 (비챕터 but 분할 단위)

```regex
^(부록|Appendix|후기|에필로그|서문|들어가며)\b
```

## 테스트 케이스 (test_split.py 골든)

```python
TRUE_CASES = [
    "제1장 FDE의 부상",
    "2장 올바른 문제 풀기",
    "Chapter 3 Activation",
    "4. Deployment",
    "부록 A 핵심 지표",
    "후기 FDE의 직업 윤리",
]
FALSE_CASES = [
    "1.1 부분 집합",       # 절 번호, 장 아님
    "Table 1. 결과",       # 표 번호
    "그림 2. 구조",        # 그림 번호
    "2026년 8월",          # 날짜
]
```

## 한계

- 목차 페이지의 `1장 ... 12` 형식은 본문 표지와 구분 필요(폰트크기·위치 힌트)
- 게이트 필수 — 자동 감지 후 사람이 chapters.json 확정(spin_chapters 게이트 규칙)
