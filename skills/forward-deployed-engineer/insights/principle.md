## ch01-4 — 현장 맞춤화 = 비용 아닌 제품 발견 (산카르 회계 반역)

단일 고객 맞춤을 서비스 비용(이익률 적)에서 제품 발견(R&D)으로 재정의. 현장 시행착오 = 플랫폼 다음 진화 이정표. 자본 배치 논리 전복. 비용 센터 → 연구개발 센터.

**근거 support_chain:**
- 현장 맞춤화는 비용이 아니라 제품 발견이다
- 엔지니어 현장 시행착오가 플랫폼 진화 이정표가 된다

**부록C 사례:** 1장-10

**원문 §:** ch01§1.2

**루브릭:** 평균 4.5 · genericity 0 · 반직관 회계 전복. principle이나 실행 함의 큼(조직 회계 처리). Foundry 근거.

## ch01-6 — FDE 소거법 — 프리세일즈/외주/컨설팅/제품엔지 아닌 것

프리세일즈(목표=수주, 결과=슬라이드) vs FDE(결과, production 시스템). 현장상주외주(공수 과금, 0부터 코딩) vs FDE(결과 과금, 제품 기반). 컨설턴트(실행 무책임) vs FDE(종착점=고객 자립). 제품엔지니어(추상 사용자) vs FDE(구체 고객).

**근거 support_chain:**
- 프리세일즈는 가능하게 믿게 만들 책임, FDE는 실제 가능하게 만들 책임
- 현장상주외주는 사람 머릿수를 팔고 FDE는 결과를 판다
- 컨설턴트는 당신이 그를 계속 필요로 하길 바라고 FDE는 필요로 하지 않길 바란다

**부록C 사례:** 1장-28, 1장-29

**원문 §:** ch01§1.3

**루브릭:** 평균 4.5 · genericity -1 · 역할 경계 명확. 한국 독자에게 현장상주외주 구분 특히 중요.

## ch01-7 — AI 시대 도화선 — 승패는 모델 품질 아닌 배포 역량

LLM이 전 무록 낙차 생성. 5분 데모 쉬워도 기업 데이터·권한·컴플라이언스·워크플로 연결은 한 차원 더 어렵다. 모델 회사들이 깨달음: 다음 판 승패 = 배포 역량. FDE 채용 9개월 8배, OpenAI/Anthropic 배포회사 동일 발표.

**근거 support_chain:**
- 다음 판의 승패는 모델 품질이 아니라 배포 역량이다
- 에이전트가 어떤 모습이어야 하는지는 아무도 모른다 — 답은 현장에서만

**부록C 사례:** 1장-22, 1장-25, 1장-32

**원문 §:** ch01§1.3

**루브릭:** 평균 4.2 · genericity 0 · 시장 구조 통찰. principle. 전략 의사결정 함의.

## ch02-6 — 잘못된 프로젝트 거절 = FDE 최고 수익 능력

FDE 비용 구조 선점형(최고 엔지니어·비싼 출장·긴 투입이 대금 회수 이전). 늪 빠지면 한 건 손해 아닌 정예팀 발 묶임·기회비용 눈사태. 세일즈 직관 거스르는 진리: 거절이 수익.

**근거 support_chain:**
- 잘못된 프로젝트 거절이 FDE 모델의 가장 중요한 수익 능력
- FDE 비용 구조는 선점형 — 일단 늪에 빠지면 정예 팀 전체가 발 묶인다

**부록C 사례:** 2장-5, 2장-6

**원문 §:** ch02§2.3

**루브릭:** 평균 4.5 · genericity 0 · 반직관(거절=수익). 비용구조 근거. principle.

## ch08-1 — 무료 파일럿 = 벤처 포트폴리오 (대가 감수 논리)

Palantir 파일럿 수백만 달러 태움, 이익률 '마이너스 무한대'. 감당한 이유 = 파일럿을 R&D 포트폴리오처럼 투자. 다수 베팅 영점 OK, 성공이 전부 회수. 전제: 천문학적 자본 두께 + 실패 파일럿 제품 자산 전환 메커니즘. 둘 다 없으면 순수 출혈.

**근거 support_chain:**
- 파일럿을 벤처처럼 때린다 — 대부분 베팅이 0이어도 문제 아니다
- 자본 두께도 없고 실패 파일럿을 제품 자산으로 전환하는 메커니즘도 없으면 순수 출혈

**부록C 사례:** 2장-6

**원문 §:** ch08§8.1

**루브릭:** 평균 4.0 · genericity 0 · 파일럿 경제학 통찰. 전제 조건 명시.

## ch08-2 — 전장 즉석 도구 — 본사 회의실에선 절대 태어날 수 없다

이라크 노상폭탄 지도 도구. 병사는 정교 정보차트 관심 없, '이 도로 수상함' 표시 원함. 엔지니어 즉석 조잡 도구 → 사상자 감소 → 플랫폼 표준기능. 오직 엔지니어+병사가 같은 도로 바라보는 순간에만 가능.

**근거 support_chain:**

- 오직 엔지니어와 병사가 같은 도로를 함께 바라보는 그 순간에만

**부록C 사례:** 1장-13

**원문 §:** ch08§8.1

**루브릭:** 평균 4.5 · genericity 0 · 현장 가치 선명. principle.

## ch08-7 — 지식 이전 약속 — 벤더 종속 의심 가장 강력한 응답

Anthropic/FIS 협업 명시적 목표 = FIS가 '장차 독자적으로 에이전트 구축·확장'하게. '고객 가르치기' 계약 명시 = 단기 대체불가능성 약화. 장기 = 벤더 종속 의심 가장 강력 응답. 가트너 2028년 70% 포기 예측 시한폭탄 미리 해체.

**근거 support_chain:**
- 고객 가르치는 것을 계약에 적는 건 단기엔 대체불가능성 약화
- 장기적으론 벤더 종속이라는 의심에 대한 가장 강력한 응답이다

**원문 §:** ch08§8.3

**루브릭:** 평균 4.2 · genericity 0 · 반직관(자기 약화). 장기 전략.

## ch08-14 — FDE 최대 적 = 자기 비용 구조 (가트너 70% 포기 예측)

얕게 하면 모델 회사가 직접. 깊게 하면 본질 외주라 인도비용 높고 규모화 어렵다. 가트너 2028년 70% 기업이 비용·역량 공동화로 FDE 주도 방식 포기 예측. Kuse.ai 창업자 "FDE 좋은 비즈니스 모델 되기 어렵다". 해법 후보 = AI 롤업(고객 회사 자체 인수).

**근거 support_chain:**
- FDE 모델 가장 큰 적은 기술이 아니라 자기 자신의 비용 구조일 수 있다
- 얕게 하면 모델 회사가 스스로, 깊게 하면 본질 외주라 규모화 어렵다

**원문 §:** ch08§8.4

**루브릭:** 평균 4.0 · genericity 0 · 한계 자각. principle. 비즈니스 타당성 핵심.

## ch09-5 — 아니오 말할 배짯짝 = 다른 고객이 당좌계좌에

프랑스 웨이터 = 고객 모든 요구 들어주는 게 아닌, 진정 유리하고 세상에 해 없는 방향 이끄는 용기. 컴플라이언스 경계 오가는 요구에 아니오. 배짯짝 = 다른 고객 있어서. 도덕 = 비즈니스 모델과 연결.

**근거 support_chain:**
- 아니라고 말할 수 있는 배짯짝은 다른 고객이 당좌계좌에 있다는 데서 나온다
- 도덕은 처음부터 비즈니스 모델과 연결되어 있다

**원문 §:** ch09§후기

**루브릭:** 평균 4.2 · genericity 0 · 도덕-비즈니스 연결 통찰. principle.

## ch03-3 — 정치 맵 — 자동화 피해자를 '새로운 출로'로 설계해야 갱신 산다

저항의 뿌리는 게으름 아니라 두려움(대체·무능 노출·존재 의미 상실). 피해자로 설계된 사람은 갱신 시점 단호 반대자. 설계 안에 새 출로 마련해야 — 막다른 길 아니라.

**근거 support_chain:**

- 피해자로 설계된 사람은 갱신 시점 단호 반대자 된다

**원문 §:** ch03§3.4

**루브릭:** 평균 4.2 · genericity 0 · 저항 원인 재정의 + 갱신 실패가 설계 단계 정치 배제에 있음. 5장 예견 인과.

## ch04-4 — 데이터 거버넌스 = AI 프로젝트의 선행 공사 아니라 곧 AI 프로젝트 자체

- 데이터 거버넌스는 선행 공사가 아니라 곧 AI 프로젝트 자체다
- 해군 조선소 생산 일정 160 인공시간 → 10분

## ch06-1 — 무료 POC 자본 회수 비대칭 — 영업 비용을 엔지니어링 비용으로 전환

무료 검증은 비용 아니라 영업 비용(출장·제안서·술자리·협상, 제품로 안 남음)을 엔지니어링 비용(제품로 쌓임)으로 바꾸는 일. 세 장부: (1) 영업→엔지 비용 전환. (2) 위험 정가에 끌어안는 힘(성공하면 그때 내세요 — 의심 녹으면 정가권 내 손으로). (3) 실패도 비싸게 실패 — 남기는 것(산업 이해·재사용 컴포넌트·평가 데이터)이 출장 영수증 뭉치와 질 다르다.

**근거 support_chain:**
- 무료 POC는 영업 비용을 엔지니어링 비용으로 바꾸는 것이다
- 실패가 남기는 것(산업 이해·컴포넌트·평가 데이터)이 출장 영수증과 질 다르다

**부록C 사례:** 6장-1

**원문 §:** ch06§6.1

**루브릭:** 평균 4.5 · genericity 0 · '무료=비용' 통념을 자본 회수 비대칭으로 재프레이밍. 제품 잔존성 차이 비자명.

## ch07-1 — 복제 레버리지 3단계 — 비용 '낮추는' 것과 '없애는' 것은 다르다

복제 레버리지 (1) 지식 복제(전법 매뉴얼) (2) 컴포넌트 복제(코드/커넥터)는 인도 비용 '낮추기만' 하고, (3) 제품 복제(플랫폼 표준 능력)는 비용 자체 '없앤다'. '고객 하나 마칠 때마다 다음 고객이 더 쉬워지는가'가 FDE와 컨설팅(맨데이 장사) 가르는 유일 진단. 맞춤 작업량이 고객 수에 비례해 줄지 않으면 FDE가 아니다.

**근거 support_chain:**
- 앞 두 단계는 인도 비용 낮추고, 세 번째는 비용 자체 없앤다
- 맞춤 작업량이 고객 수에 비례해 줄지 않으면 FDE가 아니다 — 맨데이 장사

**부록C 사례:** 7장-1

**원문 §:** ch07§7.1

**루브릭:** 평균 4.0 · genericity 0 · '비용 저감 vs 제거' 대비 + 맨데이 진단 한 문장 압축.

## ch07-5 — 현장→플랫폼 이익률 역설 — 사람 보내는 회사가 순수 소프트웨어보다 높은 이익률

'사람 현장 보내면 이익률 낮을 것' 직관 뒤집는 증거: ServiceNow 63.2%→79%, Workday 54.1%→76%, Palantir 79%→82%. 기전: 플랫폼 침전 두꺼워질수록 고객 스스로 구축(부트캠프 모델), 서비스 비용 지속 얇아진다. '먼저 흉하고 나중에 아름답고, 먼저 무겁고 나중에 가볍게'. 종착점: 현장은 탐침, 플랫폼은 레버리지, 제품은 복리 그릇 — 자강식 플라이휠.

**근거 support_chain:**
- ServiceNow 63.2%→79%, Workday 54.1%→76%, Palantir 79%→82%
- 현장은 탐침, 플랫폼은 레버리지, 제품은 복리의 그릇

**부록C 사례:** 7장-7, 7장-8, 7장-9

**원문 §:** ch07§7.8

**루브릭:** 평균 4.2 · genericity 0 · '서비스 회사=저이익률' 통념 3기업 시계열 데이터로 정면 반박. 비자명·증거 챕터 최상.
