# 호출 프롬프트 예시

## 명시 호출

```text
$korean-ebook
첨부한 ZIP의 Markdown 원고만 책 본문으로 사용해서 A4 편집 PDF로 만들어. 같이 첨부한 PDF는 디자인 예시일 뿐이므로 문장이나 목차를 합치지 마. 전 페이지 렌더링과 검수 보고서까지 만들어.
```

## FDE 프리셋 사용

```text
korean-ebook 스킬을 사용해. 표지와 장 표제지는 fde-midnight 프리셋, 본문은 한국어 명조, 제목은 고딕으로 구성해. 원문 문장은 바꾸지 말고 자동 목차와 북마크를 넣어.
```

## 참고자료 없는 원고

```text
이 Markdown 12개를 파일 번호 순서대로 합쳐 출판형 PDF로 편집해. README의 기존 목차 표는 제거하고 실제 페이지 번호가 들어가는 자동 목차로 바꿔. 내용 누락 검수까지 해.
```

## 사용하면 안 되는 요청

```text
스캔 계약서에서 도장만 지워 줘.
```

이 요청은 원고 편집이 아니라 PDF 편집·레드액션 작업이므로 다른 스킬을 사용한다.

## 1단 목차와 시각 요약 적용

```text
$korean-ebook
첨부 원고를 A4 실무서로 편집해. 목차는 반드시 1단으로 만들고, 각 장 앞에 원문에서 근거를 확인할 수 있는 개념도·흐름도·비교표를 한 페이지씩 넣어. 원고에 없는 사실이나 숫자는 만들지 말고, 전 페이지 렌더링으로 표와 도형 잘림을 확인해.
```
