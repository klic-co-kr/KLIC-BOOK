# Book 품질 게이트

이 문서는 `book` 모드 전용이다. `manual` 모드는 `manual-quality-gates.md`를 사용하며, `hybrid`는 두 게이트를 각각 통과해야 한다.

## Gate 1 — 입력 경계

- [ ] CONTENT와 REFERENCE가 분리되었다.
- [ ] 참고자료가 빌드 본문 입력에 포함되지 않았다.
- [ ] 제외 파일과 이전 결과물이 제거되었다.
- [ ] 모든 입력의 SHA-256이 기록되었다.

실패 시 빌드를 중단한다.

## Gate 2 — 내용 무결성

- [ ] 모든 원고 파일이 매니페스트에 포함되었다.
- [ ] H1/H2/H3 수가 빌드 전후에 설명 가능하게 일치한다.
- [ ] 긴 문단 표본 누락이 0건이다.
- [ ] 표·목록·각주가 사라지지 않았다.
- [ ] 원문 저작권·출처 안내가 보존되었다.

## Gate 3 — PDF 구조

- [ ] A4 페이지 크기다.
- [ ] 제목·저자·주제 메타데이터가 있다.
- [ ] 목차 링크와 북마크가 있다.
- [ ] 링크 주석이 깨지지 않았다.
- [ ] 페이지 번호가 순서대로 보인다.

## Gate 4 — 글꼴과 한글

- [ ] 사용 글꼴이 PDF에 임베딩되었다.
- [ ] 유니코드 매핑이 존재한다.
- [ ] 깨진 한글, 검은 네모, 대체문자 `�`가 없다.
- [ ] 본문·제목·코드 글꼴 역할이 구분된다.

## Gate 5 — 시각 렌더링

- [ ] 전 페이지가 이미지로 렌더링되었다.
- [ ] 표지·속표지·안내·목차·모든 장 표제지를 확인했다.
- [ ] 잘림·겹침·페이지 밖 요소가 없다.
- [ ] 제목 고아, 한 줄 과부, 빈 페이지가 없다.
- [ ] 긴 표와 목록을 원본 크기로 확인했다.

## Gate 6 — 참고자료 오염

- [ ] 참고자료 고유 문구가 최종 PDF에서 검출되지 않았다.
- [ ] 참고자료의 목차·평가표·방법론이 원고에 추가되지 않았다.
- [ ] 표지·색상·타이포처럼 시각적 특성만 재사용되었다.

## Gate 7 — 배포 패키지

- [ ] 최종 PDF만 명확한 이름으로 제공된다.
- [ ] `verification.json`과 `verification.md`가 있다.
- [ ] `source_manifest.json`과 `build_report.json`이 있다.
- [ ] 최종 PDF와 ZIP의 SHA-256이 기록되었다.
- [ ] 임시 렌더와 작업 HTML은 필요에 따라 별도 폴더에 둔다.

고위험 오류가 하나라도 있으면 상태는 `완료`가 아니라 `조건부 완료` 또는 `실패`다.
