# AI tells 회피 — 디-AI 편집 가이드

PDF 편집에서 AI 생성물 티가 나는 시각 패턴(AI tells)을 피하는 기준이다. 내용 보존 원칙(입력 경계·원문 무결성)의 시각 연장선이다. 이 가이드는 표지·장 표제지·시각 요약 페이지·표·타이포그래피에 적용한다.

## 원칙 한 줄

과장·장식·균일화를 버리고 — flat 단색 표면, 모노 라벨, 정당화된 수치, inset 깊이, 단일 액센트를 쓴다.

## 금지 (AI tells)

| 패턴 | PDF 편집에서의 형태 |
| --- | --- |
| 보라·분홍 그라데이션 | 도형·표제·배경의 `linear-gradient(purple,pink)`. gradient 텍스트. |
| 이모지 장식 | 본문·표제·도형 라벨의 ✨🚀🎯. 감정 표현용 이모지. |
| 글래스·블러 | `backdrop-filter` 흉내의 반투명 겹침. 빈 공간 채우기용 투명 레이어. |
| 4색 심각도 레일 | 표·도형을 무지개 4색으로 구분. 녹색/노랑/주황/빨강 신호등 남용. |
| 가짜 수치 | 원문에 없는 `99.9%`, `10×`, `+200%`. 근거 없는 배수. |
| 과장 카피 | "혁신적", "완벽한", "핵심", "Elevate", "Seamless" 같은 빈 수사. |
| 균일 대반경 | 모든 박스에 같은 큰 모서리 둥글림. 풍선형 카드. |
| 그라데이션 알약 | CTA·배지의 gradient pill. 테두리 없는 떠다니는 색면. |

## 대체 (디-AI)

- **flat 단색 표면** — `fde-midnight` 프리셋의 짙은 네이비·청록 단색. 도형 칸은 종이 톤 단색 채우기.
- **모노 라벨** — 숫자 인덱스 `01`, `02`와 mono 폰트 eyebrow(`CHAPTER MAP`, `WORKFLOW`)로 위치 표시. 이모지 대신 텍스트 라벨.
- **inset 깊이** — 미세 안쪽 그림자·테두리 선으로 표면을 띄운다. 블러·드롭새도 과잉 금지.
- **단일 액센트 + danger** — 구조색은 네이비/청록 1종. 위험·금지만 red. 그 외 톤은 종이 잉크 농도로 처리.
- **정당화된 수치** — 수치는 원문에 있는 것만. `font-variant-numeric: tabular-nums`로 자리 정렬.
- **원문 축약 문구** — 도형·표 문구는 해당 장·절 제목이나 본문 핵심 문장에서 추출·축약. 수사구 생성 금지.
- **계층 모서리** — 칸·태그는 미세 둥글림, 컨테이너는 약간 더 큰 둥글림. 표는 직각이 기본.

## 도형·표 적용

- `process`, `bridge`, `quadrant` 등 레이아웃의 화살표·칸은 flat 단색. gradient 화살표 금지.
- 비교표는 한 셀에 한 판단. 열 수 제한. 셀 배경은 종이 톤 단색, 구분은 테두리 선.
- 상태·단계 구분은 색이 아니라 라벨·위치·번호로. 색이 필요하면 단일 액센트 농도 차이.

## 타이포그래피

- 표제는 flat 잉크. gradient 텍스트 금지.
- 본문 명조 + 제목 고딕 역할 구분 유지. 장식용 폰트 변형 금지.
- 숫자·코드는 mono. 통계·지표는 tabular-nums.

## 게이트 (시각)

- [ ] gradient 채우기·gradient 텍스트가 없다.
- [ ] 이모지가 없다.
- [ ] 구분색이 무지개 4색 이상 쓰이지 않았다.
- [ ] 수치가 모두 원문에 근거한다.
- [ ] 과장 수사구가 없다.
- [ ] 모서리 둥글림이 계층적으로 의도되었다.
- [ ] 단일 액센트 + danger 규칙을 지켰다.

참고: 시각화 근거 경계와 도형 레이아웃 계약은 `visual-editorial-layer.md`를 따른다.
