# 편집 디자인 시스템: fde-midnight

## 1. 성격

- 장문 기술·비즈니스 실용서에 맞는 차분한 편집 디자인
- 표지와 장 표제지는 짙은 네이비, 본문은 백색 종이
- 청록색을 구조 강조에 쓰고 황금색을 제한적으로 사용
- 장식보다 정보 구조와 한글 가독성을 우선

## 2. 페이지 체계

### 표지

- A4 전면 네이비 배경
- 상단 작은 영문 아이브로
- 중앙 왼쪽 대형 한글 제목과 부제
- 오른쪽에는 선과 점으로 만든 추상 네트워크 장식
- 하단 저자, 판본 설명, 5~7개의 작은 프로세스 칩

### 속표지

- 넓은 여백의 백색 페이지
- 제목, 부제, 핵심 문장, 저자
- 페이지 번호는 유지하되 머리말은 숨김

### 편집본 안내

- 본문에 추가되는 유일한 설명 페이지
- 원고 보존 범위, 편집 범위, 저작권 조건을 짧고 명확하게 표시
- 참고자료 내용을 소개하거나 통합하지 않음

### 목차

- 2단 또는 1단 자동 선택
- 장 제목은 굵게, 절 제목은 작게
- 점선 리더와 실제 PDF 페이지 번호
- 클릭 가능한 내부 링크

### 장 표제지

- 네이비 전면 페이지
- 장 번호를 큰 반투명 숫자로 표시
- 장 제목과 장 내 H2 목록
- 머리말·페이지 번호 숨김

### 본문

- 명조 계열 본문, 고딕 계열 제목
- 넉넉한 행간과 짧지 않은 문단 간격
- 상단 좌우에 현재 장과 책의 짧은 제목
- 하단 중앙 페이지 번호

## 3. 타이포그래피

- 본문: 10.2~11.2pt, 행간 1.72~1.9
- H2: 19~23pt, 페이지 시작 시 상단 여유 확보
- H3: 13.5~16pt
- 인용문: 본문보다 약간 작게, 옅은 배경과 청록색 세로선
- 표: 8.3~9.6pt, 열 너비 고정, 긴 단어 자동 줄바꿈
- 영문·숫자 혼용 시 자간을 과도하게 좁히지 않음

권장 글꼴은 NanumMyeongjo/NanumSquare이며, 없으면 Noto Serif CJK KR/Noto Sans CJK KR로 대체한다. 글꼴 파일은 스킬에 포함하지 않는다.

## 5. 페이지 나눔

- H2/H3 뒤 첫 문단과 제목을 가능한 한 함께 둔다.
- 짧은 목록은 한 페이지에 유지한다.
- 표 머리글은 다음 페이지에서 반복한다.
- 장 표제지 다음에는 새 페이지에서 본문을 시작한다.
- 부록의 장문 표는 글자 크기를 먼저 줄이기보다 가로형 페이지나 열 구조 조정을 검토한다.

## 6. 장식 사용 한계

- 그라데이션과 장식은 표지·장 표제지에만 집중한다.
- 본문 페이지에는 그림자, 과도한 카드, 무의미한 아이콘을 넣지 않는다.
- 장식 때문에 본문 면적이 줄거나 페이지 수가 과도하게 늘어나면 장식을 제거한다.
