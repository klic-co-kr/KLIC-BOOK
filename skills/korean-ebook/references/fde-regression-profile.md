## 3. 명시적 편집 변환

README는 저장소 화면용 문서이므로 다음 항목만 설정에 따라 책의 다른 편집면으로 이동하거나 제외한다.

- H1 아래 저자·공개 안내 문장: 속표지 판본 문구로 이동
- README 맨 앞 수평선: 앞 문단 이동 후 남는 장식이므로 제거
- `읽는 법`: GitHub 온라인 열람 안내이므로 책 본문에서 제외
- 수동 `목차`: PDF 자동 1단 목차로 대체
- `저작권 안내`: 편집본 안내 페이지의 판권 상자로 이동
- 마지막 Star·공유 문장: 편집본 안내 페이지로 이동

이 변환은 `strip_front_matter_sections`, `front_matter_drop_paragraphs`, `strip_front_matter_leading_rules`에 명시되어야 한다. 일반 원고에는 자동 적용하지 않는다.

## 4. 시각 편집 무결성

- 시각 요약 12쪽의 문구는 해당 장의 제목·절 제목·핵심 문장을 축약·재배열한 것이다.
- 시각 페이지는 새로운 사례·수치·출처를 추가하지 않는다.
- 모든 시각 페이지 하단에는 원문을 대체하지 않는 편집 요약임을 고지한다.
- 도형·표의 셀은 A4에서 읽히는 길이로 제한하고 전 페이지 렌더링으로 잘림을 확인한다.

## 5. 회귀 실행

```bash
python scripts/run_pipeline.py \
  --input /path/to/FDE-manuscript.zip \
  --output-dir /path/to/out \
  --config assets/book-config.fde-example.yaml
```

빌드 후 `build_report.json`, `verification/verification.json`, PDF 북마크, 전 페이지 접촉표를 위 표와 대조한다. 이 프로필은 동일 원고의 구조 회귀를 위한 것이며, 회귀본과 바이트 또는 픽셀 단위 동일성을 보장하지 않는다.
